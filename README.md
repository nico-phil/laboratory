This repository contains a collection of classical cryptography algorithms and number theory utilities implemented for educational and experimental purposes. 
It includes implementations of well-known historical ciphers such as the Caesar cipher, Atbash cipher, route encryption, lattice-based encryption methods, Vigenère table techniques, and gaming encryption schemes.

In addition to classical encryption algorithms, the repository also includes fundamental number theory algorithms commonly used in cryptography, such as:
- Calculation of the greatest common divisor (GCD)
- Extended Euclidean algorithm
- Probabilistic algorithms for primality testing
- Other mathematical tools used in cryptographic systems


The goal of this project is to provide clear and easy-to-understand implementations of these algorithms, helping students and developers explore how classical cryptographic techniques and mathematical foundations work in practice.
Each algorithm is implemented separately so that it can be studied, tested, and reused independently.

This repository is intended for:
- learning cryptography fundamentals
- studying classical encryption techniques
- understanding number theory algorithms used in cryptography
- experimenting with algorithm implementations
